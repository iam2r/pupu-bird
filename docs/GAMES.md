# 游戏列表和操作说明

本项目包含 **5 款休闲小游戏**，在 Hub 主界面以圆角卡片列表呈现，轻触卡片即可进入对应游戏。所有游戏适配 iPhone 竖屏，使用统一的设计语言。

## 游戏 1：噗噗鸟 (Flappy Bird)

| 属性 | 值 |
|------|-----|
| 文件名 | `src/flappy-bird.js` |
| 主题色 | 珊瑚粉 `#FF9F8F` |
| 状态 | `START` → `PLAYING` → `DEAD` |

### 操作方式

- **轻触屏幕**：小鸟向上飞（flap）
- **不操作**：小鸟受重力影响自然下落
- **游戏结束**：轻触任意位置重新开始
- **返回按钮**：左上角"← 返回"

### 游戏规则

1. 控制粉红小鸟飞越不断出现的管道间隙
2. 每穿过一对管道得 **1 分**
3. 碰到管道、天花板或地面 → 游戏结束
4. 勋章系统：
   - 10 分 → 🥉 铜牌
   - 20 分 → 🥈 银牌
   - 30 分 → 🥇 金牌
5. 最高分仅内存保留，不持久化

### 物理参数

| 参数 | 值 |
|------|-----|
| 重力加速度 | 980 px/s² |
| Flap 速度 | -420 px/s |
| 最大下落速度 | 550 px/s |
| 管道滚动速度 | 120 px/s |
| 管道间距 | 屏幕高度的 17% |

## 游戏 2：贪吃蛇 (Snake)

| 属性 | 值 |
|------|-----|
| 文件名 | `src/snake.js` |
| 主题色 | 薰衣草紫 `#C5B4E3` |
| 状态 | `START` → `PLAYING` → `DEAD` |

### 操作方式

- **滑动屏幕**：改变蛇的移动方向（上/下/左/右）
- **游戏结束**：轻触重新开始
- **返回按钮**：左上角"← 返回"

### 游戏规则

1. 在 18px 网格棋盘上控制蛇吃掉红色食物
2. 每吃一个食物得 **1 分**，蛇身增长 1 节
3. 碰到墙壁或自身 → 游戏结束
4. 移动速度随得分递增：初始 0.18s/步，每吃一个食物加速 0.005s，最快 0.06s/步
5. 方向限制：**只能 90 度转向**，不能反向
6. 支持连续滑动切换方向
7. 最高分通过 `wx.setStorageSync` 持久化

### 参数

| 参数 | 值 |
|------|-----|
| 格子尺寸 | 18px |
| 网格列数 × 行数 | 动态计算 |
| 初始速度 | 0.18s/step |
| 最小速度 | 0.06s/step |
| 加速步长 | 0.005s/食物 |

## 游戏 3：方块消消乐 (Block Puzzle / Tetris)

| 属性 | 值 |
|------|-----|
| 文件名 | `src/block-puzzle.js` |
| Hub ID | `"tetris"`（注意：文件名与 ID 不一致） |
| 主题色 | 天空蓝 `#A8D8EA` |
| 状态 | `START` → `PLAYING` → `GAMEOVER` |

### 操作方式

- **左右滑动**：移动当前方块
- **下滑**：方块直接落底（硬降，每格奖励 2 分）
- **短触（点击）**：旋转方块
- **右下角 ↻ 按钮**：旋转方块（备选方式）
- **游戏结束**：点击重新开始
- **返回按钮**：左上角"← 返回"

### 游戏规则

1. 经典俄罗斯方块玩法，10×20 网格
2. 7 种标准 tetromino（I、O、T、S、Z、J、L），各具独立颜色
3. 填满一行即消除，上方方块下落
4. 消行计分：**1行=100，2行=300，3行=500，4行=800**，乘以当前等级
5. 每消 10 行升 1 级，下落速度加快（初始 800ms，每级减 70ms，最快 80ms）
6. 虚线 ghost 预览显示方块落点
7. 旋转支持墙踢偏移（7 种偏移尝试）
8. 右侧面板显示：分数、等级、最佳、行数、NEXT 预览
9. 最高分通过 `wx.setStorageSync` 持久化

### 七种方块

| 名称 | 颜色 | 色值 |
|------|------|------|
| I | 浅蓝 | `#4FC3F7` |
| O | 暖黄 | `#FFD54F` |
| T | 浅紫 | `#CE93D8` |
| S | 薄荷绿 | `#81C784` |
| Z | 珊瑚红 | `#EF9A9A` |
| J | 天蓝 | `#64B5F6` |
| L | 橘黄 | `#FFB74D` |

## 游戏 4：数字拼图 (2048)

| 属性 | 值 |
|------|-----|
| 文件名 | `src/2048.js` |
| 主题色 | 暖黄 `#FFE5A3` |
| 状态 | 事件驱动（无显式状态机，通过布尔标志管理） |

### 操作方式

- **滑动屏幕**：向滑动方向合并数字方块（上/下/左/右）
- **滑动阈值**：手指移动距离 ≥ 20px 才触发合并
- **胜利弹窗**：点击"继续游戏"按钮或弹窗其他区域关闭
- **游戏结束**：点击"再来一次"按钮或弹窗区域重新开始
- **返回按钮**：左上角"← 返回"

### 游戏规则

1. 4×4 网格，滑动方向上的相同数字合并为它们的和
2. 每次有效移动后随机空格出现新数字：
   - **90% 概率**：出现 2
   - **10% 概率**：出现 4
3. 得分 = 所有合并产生的新值之和
4. **胜利条件**：任一格子数字达到 2048（弹出胜利弹窗，可选择继续游戏）
5. **失败条件**：网格满且无可合并的相邻数字
6. 数字方块颜色随数值从粉到紫到红递进（13 级配色）
7. 最高分通过 `wx.setStorageSync` 持久化

## 游戏 5：打砖块 (Breakout)

| 属性 | 值 |
|------|-----|
| 文件名 | `src/breakout.js` |
| 主题色 | 柔粉 `#FFB3BA` |
| 状态 | `START` → `PLAYING` → `DEAD` → `GAMEOVER`（无命） |

### 操作方式

- **左右滑动手指**：控制挡板水平移动（lerp 平滑跟随，系数 0.25）
- **点击/滑动**：从 START 状态发射小球
- **游戏结束**：点击"再来一次"按钮或面板区域重新开始
- **失去一条命时**：点击继续（球重置到挡板上）
- **返回按钮**：左上角"← 返回"

### 游戏规则

1. 挡板反弹小球击碎 5 行 × 8 列的彩色砖块
2. 每击碎一个砖块得 **10 分**
3. 初始 **3 条命**，球掉落底部失去一条命
4. **全部清除**：砖块全部击碎后重生（颜色旋转），并奖励一条命（最多 5 条）
5. 命耗尽 → 游戏结束
6. 球反弹角度根据击中挡板位置变化：左端 30°，右端 150°（以水平右为 0°）
7. 左右墙壁和天花板反弹
8. 顶级 UI 栏显示分数、爱心剩余命数、最佳分数
9. 最高分通过 `wx.setStorageSync` 持久化

### 砖块颜色

| 行 | 填充色 | 边框色 |
|----|--------|--------|
| 第 1 行 | `#FFB3B3`（珊瑚粉） | `#F09898` |
| 第 2 行 | `#FFD4B3`（杏橙） | `#F0B888` |
| 第 3 行 | `#FFE5A3`（奶油黄） | `#F0D070` |
| 第 4 行 | `#C5E8C5`（薄荷绿） | `#A0D0A0` |
| 第 5 行 | `#C5B4E3`（薰衣草紫） | `#A898D0` |

### 物理参数

| 参数 | 值 |
|------|-----|
| 球速 | 380 px/s |
| 砖块列数 | 8 |
| 砖块行数 | 5 |
| 初始生命 | 3 |
| 最大生命 | 5 |
| 挡板 lerp 系数 | 0.25 |
| 挡板宽度比 | 屏幕宽的 18% |

## 通用操作

| 操作 | 方式 |
|------|------|
| 进入游戏 | Hub 中轻触游戏卡片 |
