# 噗噗鸟 产品设计文档

## 定位

女性向休闲小游戏，操作简单、画面可爱、情绪起伏大（死得快 → 多看广告复活 → 多变现）

## 变现模型

| 功能 | 描述 | 变现点 |
|------|------|--------|
| 🎀 **主题皮肤** | 樱花、海洋、星空、万圣 4 套主题（鸟色/管道色/背景） | 看广告解锁 |
| 🐣 **小鸟换装** | 帽子、墨镜、蝴蝶结、腮红等配饰 | 看广告抽 |
| 🌸 **花瓣特效** | 飞过管道洒花瓣、死亡飘花瓣 | 纯视觉，提高传播 |
| 📸 **死亡纪念卡** | 精美结算卡（分数+鸟鸟插画），可保存/分享 | 自然传播引流 |
| 💕 **双人模式** | 同屏两只鸟，对战/合作 | 话题性 |
| 🏆 **每日挑战** | 随机障碍布局 | 留存 |

## 开发优先级

| 优先级 | 功能 | 理由 |
|--------|------|------|
| ✅ 已完成 | 花瓣特效、死亡纪念卡 | 已实现 |
| ✅ 已完成 | 3 套主题 + 配饰系统 | 已实现 |
| ✅ 已完成 | 积分系统 + 调试按钮 | 已实现 |
| 🔜 Phase 2 | 接入真实广告（wx.createRewardedVideoAd） | 开始变现 |
| 🔜 Phase 3 | 双人模式 | 话题传播 |
| 🔜 Phase 4 | 每日挑战 | 提高留存 |

## 小红书传播策略

1. **死亡纪念卡** + `#噗噗鸟` 话题 — 截图自然传播
2. **换装截图九宫格** — "今天给噗噗穿了小帽子"
3. **挑战帖** — "你能过 50 分吗"

## 技术栈

- 微信小游戏 Canvas 2D
- 纯单机，零后端成本
- 积分/主题/配饰：`wx.setStorageSync` 本地存储
- 广告：`wx.createRewardedVideoAd`
