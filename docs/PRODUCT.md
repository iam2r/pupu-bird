# 噗噗鸟 产品设计文档

## 游戏概述

**噗噗鸟**是一款女性向休闲飞行小游戏。玩家操控一只圆滚滚的小鸟，穿越管道障碍、收集金色星星，在清新治愈的画风中挑战高分。

---

## 核心玩法

| 操作 | 机制 |
|------|------|
| **轻按跳跃** | 快速点击穿越管道，适合精准闪避 |
| **按住蓄力** | 长按蓄力后松手，跳得更高更远，同时叠加分数倍率 |
| **收集星星** | 管道间随机出现金色星星，吃星积累连击 |
| **连击系统** | 连续吃星触发 GOOD→GREAT→AMAZING→FANTASTIC→LEGENDARY 五档，旋律递增 |
| **无敌状态** | 每 3 连击触发金光无敌，撞管不死，时间随连击递增 |

### 分数体系

- 穿越管道：基础 1 分 × 蓄力倍率（x1~x5）
- 收集星星：基础 2 分 × 蓄力倍率 + 连击加成（+1~+4）
- 连击 5/7 有里程碑积分奖励
- 纪念卡展示「得分 + 管道数 + 均分/管」

## 促进功能价值

| 功能 | 用户价值 | 产品价值 |
|------|----------|----------|
| 蓄力跳跃 | 操作有深度，高手菜鸟拉开差距 | 提高留存和技巧讨论 |
| 连击系统 | 消消乐式正反馈，吃星上瘾 | 单局时长增加，广告曝光机会多 |
| 10 套主题 | 收集驱动力，每天换装 | 激励视频广告变现入口 |
| 10 款配饰 | 个性化装扮，晒图传播 | 社交裂变素材 |
| 纪念卡 | 精美结算画面，可保存分享 | 自然传播引流 |
| 无敌机制 | 新手保护，降低挫败感 | 提高次日留存 |
| 分层难度 | 轻按随便玩 / 蓄力冲高分 | 覆盖休闲和硬核双人群 |

## 技术栈

- 微信小游戏 Canvas 2D 原生开发
- 纯单机，零后端成本
- 数据本地持久化：wx.setStorageSync
- 程序化音效：wx.createWebAudioContext（零音频文件）
- 10 主题 + 10 配饰，Canvas 实时渲染
